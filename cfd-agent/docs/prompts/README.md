# Prompts and Specs

This directory preserves the project prompts/specifications used to build the CFD Agent.

Files may include:

- `PROJECT_SPEC_FOR_CODEX.md`: repository-local implementation spec.
- `PROJECT_SPEC_FOR_CODEX_CFD_AGENT.md`: original task checklist/spec from Desktop, when available.
- `PROJECT_SPEC_FOR_CODEX_CFD_AGENT_SW_SC_FM.md`: revised SolidWorks/SpaceClaim/Fluent Meshing spec from Desktop, when available.

These files are reference inputs for future Codex sessions. Runtime configuration lives in `configs/`, and executable script templates live in `src/cfd_agent/templates/`.
