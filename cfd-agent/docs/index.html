Windows 本地 CFD 自动化 Agent

CFD Agent

用一个本地网页入口串联 SolidWorks、SpaceClaim、Fluent Meshing 和 Fluent Solver， 支持自然语言任务、分段运行、全流程自动、案例管理、错误诊断和验证案例复用。

下载发布包 打开 GitHub 仓库 查看启动步骤
本地运行 GitHub Pages 只做入口页，Agent 在你的 Windows 工作站运行。
已验证案例 包含 sphere_001 验证案例和完整输出结构。
分段串联 支持从任意阶段恢复：CAD、流体域、网格、求解、报告。
前台运行 SolidWorks、SpaceClaim、Fluent 可按要求在前台启动。

Agent 能做什么

第一版网站作为安装与启动入口，实际计算仍在本地软件环境中完成。

自然语言任务

输入“直径 0.1 m 球体外流场，入口 30 m/s”这类描述，Agent 会解析成结构化任务。

CAD 与流体域

生成 SolidWorks 模型，或导入自定义 CAD，再通过 SpaceClaim 创建外流场流体域。

Fluent 网格与求解

执行 Fluent Meshing Watertight Workflow，生成体网格，再进入 Fluent Solver 保存 case/data。

参数化编辑器

几何、流体、外流场、网格、求解参数可以一步一步设置，也可以保存成案例 JSON。

错误诊断中心

读取日志、质量报告和 pipeline state，定位缺边界、网格质量、输出文件缺失等问题。

部署检查

检查 Python、依赖包、SolidWorks、SpaceClaim、Fluent 路径，并运行软件 smoke check。

启动本地 Agent

  1. 下载仓库或发布包 从 GitHub Releases 下载 zip，或者 clone 仓库到本地 Windows 工作站。
  2. 安装 Python 依赖 在项目目录执行依赖安装命令。 
    py -m pip install -r requirements.txt
  3. 配置软件路径 复制 .env.example 为 .env，填写 SolidWorks、SpaceClaim、Fluent 路径。
  4. 启动网页入口 运行批处理文件，浏览器打开本地 Agent。 
    .\CFD_Agent_Web.bat
http://127.0.0.1:8765/

GitHub Pages 设置

根据 GitHub Pages 官方说明，发布源可以选择仓库根目录或 /docs 文件夹。 本项目第一版网站已经放在 docs/index.html。

  1. 进入仓库 Settings 打开 GitHub 仓库，进入 Settings -> Pages。
  2. 选择发布源 选择当前分支，文件夹选择 /docs。
  3. 保存并等待构建 构建完成后访问 https://quanxinw17-code.github.io/cfd-agent/。
GitHub Pages 不能直接启动你电脑上的 SolidWorks、SpaceClaim 或 Fluent；它负责展示入口和下载说明，本地 Agent 负责真正运行软件。
